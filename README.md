# FaaLinks

A premium personal landing page — inspired by Linktree but designed as a unique, modern personal brand experience.

Built with HTML, CSS, and Vanilla JavaScript. No frameworks, no libraries, no CDN.

## Tech Stack

- HTML5
- CSS3 (CSS Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Express (development server)
- Vercel (deployment)

## Design

- Light Blue Sea Theme
- Glassmorphism
- Smooth animations at 60 FPS
- Fully responsive (desktop, tablet, mobile, landscape)
- 8px spacing system

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:2030](http://localhost:2030)

## Project Structure

```
public/
├── index.html
├── css/      (7 modular stylesheets)
├── js/       (6 modular scripts)
└── assets/   (images, icons, fonts)
config/       (JSON data files)
server.js     (Express dev server)
vercel.json   (deployment config)
```
